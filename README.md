# Totem Slot (CereWare)

Mod Fabric para Minecraft 26.3: un hueco extra en la pantalla de la tecla **C** para tótems de la inmortalidad (admite tantas unidades como permita el tótem, también con mods que los apilan a 64).

- Al morir se usa primero el tótem de la mano (vanilla); si no hay, se gasta **uno** del hueco.
- Config `config/totemslot.json`: `keepTotemsOnDeath` (por defecto `false`).

Requiere Fabric API. Incluye la librería CereWare Slots.
